# Lecteur IPTV (Android + Android TV)

- Saisie de l'adresse du serveur (lien M3U direct ou Xtream : adresse + utilisateur + mot de passe)
- Liste des chaînes avec logos, groupes et recherche
- Lecteur Media3/ExoPlayer (HLS, TS, MP4...)
- Changement de chaîne : ▲/▼ de la télécommande, touches CH+/CH-, ou boutons à l'écran
- Compatible télécommande Android TV / Mi Box (navigation D-pad, icône bannière)
- Cache hors-ligne de la dernière liste

## Compiler
1. Ouvrir le dossier dans Android Studio (Koala ou plus récent) -> Build > Build APK.
2. Ou envoyer le dossier sur GitHub : l'onglet Actions produit app-debug.apk automatiquement.
